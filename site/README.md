# AWS Codeathon 2K26 — GIST AWS Club

Static website, no build step. Open `index.html` in a browser.

```
index.html      page markup (Home, About, Rounds, Prizes, Register, Rules)
styles.css      all styling
script.js       countdown, timeline, routing, share, cheat-sheet viewer
assets/         logo, prizes poster
```

Edit dates and links at the top of `script.js` (ROUND1, ROUND2, FORM_URL, MEETUP_URL).

The cheat sheet is served from Google Drive (download button + "View online" preview).
To change the file, replace the Drive file ID in `index.html` (3 places).
